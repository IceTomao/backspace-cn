## 更新内容

- **Windows 开启系统 HDR 时的 SDR 直播自动防过曝色调映射**：桌面端原生 SDR 直播引擎现在会自动检测被共享屏幕或被共享窗口所在显示器的系统 HDR 状态。当显示器开启 HDR 时，采集层自动切换至 16-bit 浮点线性光（`scRGB`），读取 Windows「SDR 内容亮度」白点与显示器峰值亮度，并在 GPU 着色器内实时完成 OBS 同款 Extended MaxRGB Reinhard 色调映射与标准 sRGB 转换，彻底解决开启系统 HDR 后 SDR 直播画面高光死白过曝、红叶发白偏橙的问题；SDR 显示器继续保持 8-bit 轻量直采，零额外开销。
- **新增 OBS 同款「强制使用标准动态范围 (SDR)」开关**：在开播前抽屉与直播中快捷流设置面板同步提供该开关（默认关闭，开启即复刻 OBS 勾选后的 8-bit 直采行为），支持直播中途热切换。同时支持直播期间实时响应 `Win + Alt + B` 开关系统 HDR、拖动系统「SDR 内容亮度」滑块或将共享窗口跨显示器拖放，全程不断流。
- **新增 SDR 直播实时「曝光微调 (EV)」滑块**：在 Windows 桌面端 SDR 模式的「色彩通道」折叠面板内新增 `-3.0 ~ +3.0 EV`（步进 `0.1`，双击复位 `0.0 EV`）曝光微调滑块，通过原生 GPU 常量缓冲管道实时生效（延迟 `< 8ms`，不重启编码器），方便应对不同 HDR 游戏内置亮度差异。

## 线上升级提示

- **本次升级无需重新部署服务端**（完全兼容 `1.5.3` 及以上服务端 `nativeSdrProtocol: 1`），仅需将 Windows 客户端升级至 `1.5.5` 即可生效。
