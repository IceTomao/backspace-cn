## 更新内容

- 直播「流设置」新增可折叠的「色彩通道」面板（遵循 NVIDIA 桌面颜色设置标准）：
  - 支持「所有通道 / 红色 / 绿色 / 蓝色」四组独立曲线调节（亮度 `0%–100%`、对比度 `0%–100%`、灰度 Gamma `0.30–2.80`），单通道微调在「所有通道」基准上叠加生效，切换通道不会覆盖已有参数。
  - 分隔线下方提供全局「数字亮丽（`0%–100%`，默认 `50%`）」与「色调（`0°–359°`，默认 `0°`）」调节。
  - 支持实时数值显示、双击单个滑块重置单项、一键「恢复默认」以及跨场次自动持久化保存。
- 普通 SDR 直播与实验性 Windows 原生 HDR 直播均支持主播端编码前 GPU 实时调色：开播前预览实时可见，直播中调整无需重新采集或重连即可同步呈现给所有观众；默认参数下保持原帧直通无额外开销。
- 「HDR 画面调整」精简保留 HDR 专属的「曝光度（`-3.0～+3.0 EV`）」，原 HDR 亮度统一合并至「色彩通道」管理；Windows 原生 HDR 控制管道升级至 `HDC2` 协议。
- 直播中「流设置」浮动菜单拓宽并支持纵向自适应滚动。

## 线上升级与测试准备

Windows 客户端与服务器镜像建议同步更新至 `1.5.0`。桌面客户端加载服务器提供的网页，且原生 HDR 直播中的实时调色依赖 `1.5.0` 客户端的 `HDC2` 控制协议。

服务器默认关闭实验性 HDR；如需测试 HDR 直播间，请在服务器 `.env` 中设置 `LIVEKIT_NATIVE_HDR_ENABLED=true` 并重建应用容器，同时确保 LiveKit 允许 `video/h265` 和 `audio/opus`：

```yaml
room:
  enabled_codecs:
    - mime: audio/opus
    - mime: video/h265
    # 保留现有 SDR 视频及其他音频 codec 条目
```

更新应用镜像 `ghcr.io/icetomao/backspace-cn:1.5.0` 后，确认服务器版本及新网页生效再刷新客户端。首期 HDR 发布仍要求 Windows、系统设置中已开启 HDR 的显示器以及支持 HEVC Main10 的 NVIDIA 显卡。
