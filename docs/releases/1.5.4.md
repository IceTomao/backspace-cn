## 更新内容

- **Windows「共享窗口」原生 GPU 零拷贝高刷直播**：桌面端「窗口」共享正式接入与「屏幕」共享同源的原生 GPU 零回读引擎（`WGC ForWindow → D3D11 着色器等比缩放与 BT.709 NV12 转换 → NVENC 硬件超低延迟编码 → RTP 直推`），彻底解决共享单窗口直播高负载 3D 游戏时掉帧至 30~40fps 的瓶颈，同样支持最高 `2K / 原画 @ 120fps`。
- **窗口专属进程树音频隔离（防回声）**：共享窗口并开启「共享系统音频」时，原生音频引擎优先通过 WASAPI 进程树环回（`VAD\Process_Loopback`）仅采集被共享窗口所属程序（含子进程及 UWP 游戏宿主真实进程）的声音，自动隔绝语音房间队友说话回声与系统提示音；旧版系统不支持时自动无感回退全局系统音频。
- **窗口动态缩放、最小化与关闭无缝适配**：直播期间拖动窗口尺寸或切换窗口/无边框全屏时，GPU 内实时重建采集缓冲并自动等比居中补黑边，全程 0 黑屏、不断流不重连；窗口最小化时保持推流并停留在最后一帧、恢复后立即无缝继续；窗口关闭时自动干净结束直播。
- **新观众进场瞬发关键帧修复**：对齐桌面端原生 SDR `keyframe` IPC 动作，新观众点开直播时立即触发编码器输出 IDR 关键帧，消除最长 2 秒的首屏等待。

## 线上升级提示

- **本次升级无需重新部署服务端**（兼容 `1.5.3` 及以上服务端 `nativeSdrProtocol: 1`），仅需将 Windows 客户端升级至 `1.5.4` 即可启用窗口零拷贝直播。
