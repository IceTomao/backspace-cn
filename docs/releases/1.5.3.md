## 更新内容

- **Windows 原生 GPU 零回读高刷推流管线**：桌面端「屏幕」共享新增并默认启用原生 GPU 零回读引擎（`DXGI 桌面复制 → D3D11 着色器缩放与 BT.709 NV12 转换 → NVENC / AMF / QSV 硬件低延迟编码 → RTP 直推`），全程零 CPU 显存回读，彻底解决开启全屏/无边框 3D 游戏时受 DWM 合成锁影响掉帧至 30~42fps 的瓶颈。
- **解锁 2K (1440p) / 原画 (Native) 与 120fps 高码率直播**：服务端与客户端默认开放 `540p / 720p / 1080p / 1440p / 原画` 分辨率、`30 ~ 120fps` 帧率及最高 `35 Mbps` 码率上限（维持 4K 锁定），游戏模式自动联动保帧率策略。
- **观众解码能力实时协商与 H.265 → H.264 无缝热切换**：观看端进场自动上报 H.265 硬件解码支持并触发实时 IDR 关键帧请求；当 Firefox 等不支持 WebRTC H.265 的观众加入时，「自动」模式自动无缝切换至满帧率硬件 H.264，消除 `0 fps / 0 kbps H265` 卡死与 `VP8 @ 30fps` 软编锁帧回退。
- **默认暂停主播本地自预览与窗口采集零 CPU 缩放**：主播本机直播卡片默认暂停本地二次解码预览（支持一键按需开启预览），降低同机高刷游戏合成负载；窗口共享回退路径改用硬件编码器端缩放（`scaleResolutionDownBy`）。
- **「连接信息」实时瓶颈诊断面板**：直播上行连接面板新增采集帧率、编码帧率、单帧硬编/软编耗时以及实时瓶颈智能诊断提示。

## 线上升级提示

- **Windows 客户端与服务器镜像建议同步更新至 `1.5.3`**（镜像：`ghcr.io/icetomao/backspace-cn:1.5.3`）。原生 GPU 零回读 SDR 推流协议（`nativeSdrProtocol: 1`）需服务端与 Windows 桌面客户端同时处于 `1.5.3` 及以上版本方可自动激活。
