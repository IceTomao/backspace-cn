## 更新内容

- Windows 新增默认关闭的实验性 HDR 直播间开关；仅发布一路 HEVC Main10、10-bit、BT.2020/PQ 视频。
- HDR 采集、色彩转换和编码使用 WGC / D3D11 / NVENC GPU 路径。
- 直播流设置新增曝光度（-3～+3 EV）、亮度（-50～+50）和恢复默认；支持开播前保存和直播中实时调整，所有观看者同步看到调整结果。
- HDR 开关在直播中锁定。HDR 关闭时保留原有 SDR 编码偏好和直播流程。
- HDR 直播标记按主播同步；不支持的网页、安卓及 Windows 环境显示不支持提示，不订阅该直播的视频和系统音频，频道语音正常。

## 线上测试准备

Windows 客户端和服务器网页都需要更新至本版本。桌面客户端加载服务器提供的网页，仅更新安装包不会更新直播设置界面。

服务器保持默认关闭 HDR；测试时在服务器 `.env` 中设置 `LIVEKIT_NATIVE_HDR_ENABLED=true`，重新创建应用容器以加载环境变量。LiveKit 必须允许 `video/h265` 和 `audio/opus`，例如在现有配置中合并：

```yaml
room:
  enabled_codecs:
    - mime: audio/opus
    - mime: video/h265
    # 保留现有 SDR 视频及其他音频 codec 条目
```

更新应用镜像 `ghcr.io/icetomao/backspace-cn:1.4.10` 后，确认服务器版本及新网页已生效，再刷新客户端。此版本发布会构建容器镜像，不会自动修改自建服务器的配置或部署。

首期 HDR 发布要求 Windows、系统 HDR 已开启的所选显示器及 NVIDIA NVENC Main10。观看前仍会实际检查 HDR 解码、D3D11 10-bit 渲染与当前显示器 HDR 状态；无法确认时拒绝观看，不自动转换成 SDR。

## 验证范围

网页 1180 项、桌面 282 项回归测试通过；另有设置迁移、调节合并、会话取消、参数边界及服务器 HDR 轨道证明检查。真实 GPU 合成测试验证曝光/亮度调节、恢复默认和单编码器；4K60 节奏测试及合成 Main10/PQ + Opus 经本地 LiveKit 转发、直接转封装检查通过。

**实验性功能，尚未完成双机 HDR 显示验收。** 真实 WGC 采集、高光显示、音画同步、跨显示器和长时间负载需在 HDR 硬件环境继续联测。HDR 默认关闭，SDR 路径已做自动回归；不能据此保证所有线上设备完全没有回归。
