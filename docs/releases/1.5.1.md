## 更新内容

- **桌面端防后台降频与电源护航**：启动时关闭 Chromium 后台与窗口遮挡限速，开播期间启用系统防休眠电源保护，解决全屏游戏遮挡客户端窗口时 Windows EcoQoS 将推流帧率压低的问题。
- **默认零拷贝直通与独立 Worker 调色**：色彩滑块处于默认值时直接走操作系统原帧零拷贝硬件编码通路；开启自定义色彩调节时自动转移至 `OffscreenCanvas` 独立 Worker 渲染，脱离 UI 主线程。
- **自动硬件编码优先（Auto HW）与单路按需备流**：直播设置新增并默认启用「自动（硬编优先）」，自动探测显卡硬编能力（`H.265 → H.264 → VP9`），备流策略切换为 `REGRESSION` 按需回退，并在意外回退至 CPU 软编时给出提示。
- **拥塞控制护栏与清晰度优先**：SDP 协商注入屏幕共享专属起步码率与保底码率护栏，默认拥塞策略调整为「保清晰度」（支持手动切换保清晰度 / 保流畅度 / 均衡），修正 Native 原生分辨率首帧码率计算并移除强制补帧下限。
- **观看端 120ms 抗抖动缓冲与自适应流隔离**：远端屏幕共享视频与系统伴音默认启用 `120ms` 轻量抗抖动缓冲（不影响麦克风实时语音），右键菜单支持一键开启「超低延迟模式」，并隔离观看画面的自动降分辨率与后台停流。
- **LiveKit SFU 高帧率调优配置**：更新 `install.sh`、`deploy/portainer-compose.yml` 与 `deploy/livekit.recommended.yaml`，增大视频重传环形缓冲、抑制瞬时关键帧风暴并禁止 SFU 主动暂停屏幕共享轨道。

## 线上升级提示

- **Windows 客户端与服务器镜像建议同步更新至 `1.5.1`**（镜像：`ghcr.io/icetomao/backspace-cn:1.5.1`）。桌面端主进程新增的防后台限速参数需安装 `1.5.1` 桌面客户端安装包或通过应用内更新升级后生效。
- **存量服务器 LiveKit 热升级**：已部署服务器建议参照 `deploy/livekit.recommended.yaml` 在 `livekit.yaml` 的 `rtc:` 段补充 `packet_buffer_size_video: 1500`、`pli_throttle` 与 `congestion_control: { enabled: true, allow_pause: false }`，调大宿主机 Linux UDP 缓冲区后重启 `livekit` 容器。
