# Backspace 安卓中文客户端 1.0.0

交付日期：2026-09-21。包名 `me.kevz.backspace`，versionCode `1`。

## 安装

1. 将 `Backspace-CN-1.0.0-android.apk` 传到手机，通过可信文件管理器打开。
2. 如系统提示，为此次使用的文件管理器临时允许“安装未知应用”。无需关闭手机安全防护，安装后可关闭该项授权。
3. 支持 Android 12/API 31 以上，APK 同时包含 ARM64 和 ARMv7。需要 Android System WebView 118 以上，可使用手机厂商提供的 WebView 更新渠道，不需要 Google 服务。
4. 首次启动默认简体中文和 `https://chat.kevz.me:2096`。使用已有账号登录；本安装包没有预置账号。
5. 后续同包名、同签名且版本号不降低的 APK 可覆盖安装；不要先卸载，否则账号和本地设置会被删除。

这是独立安卓工程，没有修改或部署线上前端、后端、数据库，也没有替换既有 Windows 安装文件。

## 功能入口

- 手机“我 → 设置 → 设备外观”：主题（跟随系统、浅色、深色）、后台在线开关、服务器切换。
- 默认跟随系统主题；手动主题保存在本机，切换服务器后仍保留。
- 登录页“服务器设置”也可切换地址。切换前会提示结束当前通话，各服务器的登录和本地缓存相互隔离。
- “设置 → 语音”：通话中的音频设备、蓝牙耳机授权和接收音量。耳机路由以实际设备可用列表为准。
- 聊天支持图片和文件。上传使用系统选择器；下载使用系统“保存到”选择器，仅保存已连接服务器的附件。
- 私聊、群组和频道使用原生 LiveKit 音频；不提供摄像头或屏幕共享，也不订阅通话的视频、共享屏幕或共享音频轨道。聊天附件中的普通图片、音频和视频仍保留。
- 外部链接交给浏览器；第三方内嵌网页不进入原生桥，本包禁用 iframe 嵌入。
- APK 内置网页资源，不使用网页 Service Worker 更新。新版由维护者提供同签名安装包。

## 权限和后台

| 权限 | 用途 |
| --- | --- |
| 网络、网络状态 | 连接所选服务器及 LiveKit |
| 麦克风、修改音频设置 | 用户主动加入或接听后的语音 |
| 通知 | 持续通话、后台在线及在线期间的消息/来电提醒 |
| 蓝牙连接 | 用户主动授权后选择蓝牙耳机 |
| 前台服务、麦克风前台服务、远程消息前台服务、唤醒锁 | 系统允许范围内维持通话及主动开启的后台连接 |

没有申请通讯录、短信、无障碍、全部文件访问、摄像头或屏幕录制权限。附件保存采用用户选定的受限 URI，不开放任意本地文件读取。

后台在线默认关闭。开启后会显示常驻通知；关闭且无通话时，退到后台会停止业务连接。通话通知提供静音和挂断，后台无需等待网页恢复即可执行。系统通知权限被拒绝时会提示，不能把通话或后台在线当成已经启用。

来电通知只在原生连接在线时有效。点击通知进入应用后才能接听，不会在后台擅自开麦。锁屏通知使用私密可见性，敏感内容最终还受手机的通知隐私设置控制。

小米、OPPO、vivo、荣耀等系统可能限制后台运行。用户可按需要在系统应用设置中允许后台运行并保留通知；无需开启无障碍或关闭系统安全防护。应用被清理、强制停止、断网或进入严格省电状态后，不保证即时消息和来电提醒。重新打开后会恢复连接并同步消息。

## 数据与签名

- 账号凭据由 Android Keystore 的 AES-GCM 密钥保护，按服务器加密保存；网页层仅保留运行时副本。
- 退出账号会清除当前服务器及其关联实例的本地登录凭据。切换服务器不删除另一服务器的独立账号记录。
- 禁止系统备份应用数据，避免把无法在另一设备解密的凭据恢复过去。
- APK 只包含公开地址，没有 `.env`、JWT/LiveKit 服务端密钥、签名私钥、密码或测试账号。
- 发行使用专用固定 RSA 3072 位密钥。密钥和密码在构建电脑 `%LOCALAPPDATA%\BackspaceAndroidSigning`，不在 Git、源码 ZIP 和本交付目录。
- 维护者必须私下备份该目录的 `backspace-release.p12` 和 `signing.json`，不要把它们发送给 APK 使用者。后续更新必须沿用此密钥，丢失后无法保持同签名覆盖安装。

## 对应源码和重建

源码 ZIP 包含本次实际工作区代码（包括尚未提交的现有 Windows 定制），排除了依赖、构建缓存、安装包、数据库、私钥与私人配置。保留项目 AGPL-3.0 许可证和依赖许可证。

工具版本：Java 21、Capacitor 8.5.2、Gradle 8.14.3、AGP 8.13.0、Kotlin 2.2.20、LiveKit Android 2.29.0；Android min 31、compile/target 36。包管理器锁文件和 Gradle 依赖锁文件随源码交付。

在 Windows 构建机配置 `JAVA_HOME`、`ANDROID_HOME` 后，在源码根目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm --filter @backspace/web test
node scripts/check-i18n.mjs
./scripts/build-android-release.ps1
node scripts/package-android-delivery.mjs
```

首次发行时构建脚本会创建独立私钥；已有私钥则复用。其他电脑必须先私下恢复原密钥和密码目录，不能生成另一把密钥来冒充覆盖更新。只有有意升级依赖时才使用 `-UpdateLocks`。
